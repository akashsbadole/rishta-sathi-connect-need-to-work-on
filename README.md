## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Git
- SQLite (development) or PostgreSQL (production)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/rishta-sathi.git
cd rishta-sathi
```

2. **Install dependencies**
```bash
npm install
```

3. **Database Setup**

For SQLite (Development):
```bash
# SQLite database will be created automatically
npm run db:setup
```

For PostgreSQL (Production):
```bash
# Create PostgreSQL database
createdb rishta_sathi

# Set DATABASE_URL in .env
DATABASE_URL="postgresql://username:password@localhost:5432/rishta_sathi"

# Run migrations
npm run db:migrate
```

4. **Environment Configuration**
```bash
# Copy environment template
cp .env.example .env

# Configure your environment variables
# Edit .env with your database credentials and API keys
```

5. **Start Development Server**
```bash
npm run dev
```

6. **Access the Application**
- Open browser to `http://localhost:5173`
- Register a new account or use demo credentials

### Environment Variables
```env
# Database Configuration
DATABASE_URL=sqlite:./dev.db  # SQLite for development
# DATABASE_URL=postgresql://username:password@localhost:5432/rishta_sathi  # PostgreSQL for production

# Authentication
JWT_SECRET=your-super-secret-jwt-key
JWT_EXPIRY=24h

# Payment Gateways
RAZORPAY_KEY_ID=your-razorpay-key-id
RAZORPAY_KEY_SECRET=your-razorpay-secret
STRIPE_PUBLISHABLE_KEY=your-stripe-publishable-key
STRIPE_SECRET_KEY=your-stripe-secret-key

# Communication Services
TWILIO_ACCOUNT_SID=your-twilio-account-sid
TWILIO_AUTH_TOKEN=your-twilio-auth-token
SENDGRID_API_KEY=your-sendgrid-api-key

# File Storage
AWS_ACCESS_KEY_ID=your-aws-access-key
AWS_SECRET_ACCESS_KEY=your-aws-secret-key
S3_BUCKET_NAME=your-s3-bucket

# External APIs
AADHAAR_API_KEY=your-aadhaar-verification-key
MAPS_API_KEY=your-google-maps-key
SOCIAL_AUTH_FACEBOOK_KEY=your-facebook-app-id
SOCIAL_AUTH_GOOGLE_KEY=your-google-client-id
```

## 📱 API Documentation

### Authentication Endpoints
```
POST /api/auth/register - User registration with OTP
POST /api/auth/login - User login with JWT
POST /api/auth/verify-otp - OTP verification
POST /api/auth/refresh-token - Refresh JWT token
POST /api/auth/forgot-password - Password reset request
POST /api/auth/reset-password - Password reset confirmation
```

### Profile Management
```
GET /api/profile/:id - Get user profile
PUT /api/profile/:id - Update profile information
POST /api/profile/photos - Upload profile photos
DELETE /api/profile/photos/:id - Delete photo
GET /api/profile/analytics - Profile performance metrics
```

### Search & Matching
```
POST /api/search - Advanced profile search
GET /api/matches - AI-recommended matches
GET /api/compatibility/:id - Compatibility analysis
POST /api/interests - Send interest to profile
GET /api/interests - Get sent/received interests
```

### Communication
```
GET /api/conversations - Get conversation list
POST /api/conversations - Start new conversation
GET /api/messages/:conversationId - Get messages
POST /api/messages - Send message
PUT /api/messages/:id/read - Mark message as read
```

### Background Verification
```
POST /api/verification/initiate - Start verification process
POST /api/verification/documents - Upload verification documents
GET /api/verification/status - Check verification status
GET /api/verification/report - Get verification report
```

### Wedding Services
```
GET /api/wedding/vendors - Browse wedding vendors
POST /api/wedding/booking - Book wedding service
GET /api/wedding/bookings - Get user bookings
PUT /api/wedding/booking/:id - Update booking
```

### Subscription Management
```
GET /api/subscriptions/plans - Get available plans
POST /api/subscriptions/subscribe - Subscribe to plan
PUT /api/subscriptions/upgrade - Upgrade subscription
POST /api/subscriptions/cancel - Cancel subscription
```
